# Photographer Website

A one-page personal site for a freelance wedding and portrait photographer: hero with a single button to the contact section, a three-column portfolio grid, a short about section and a simple email contact block. No navigation bar.

## Files

- `index.html`: the whole site (plain HTML and inline CSS, no build step). Open it in a browser.
- `images/`: put the portfolio photos here as `portfolio-1.jpg` and `portfolio-2.jpg`. Photos 3 to 6 are placeholders in `index.html`; swap each placeholder `<div>` for an `<img>` tag like the first two.

## To personalise

Replace the bracketed text in `index.html`: `[Her Name]`, `[city]`, the about-section line, and `[hello@yourname.com]` (also update the `mailto:` link).
